# creami-lab

Ninja Creami Deluxe recipe knowledge base, adapted for Greece.

184 recipes from [ice-creamery](https://github.com/jhermann/ice-creamery), FitnessProductFinder, and Exercise4CheatMeals — with ingredient swaps for what's actually available here, validated against [Scoopulator](https://scoopulator.app).

Built to be used with Claude Code as an AI recipe assistant. See `CLAUDE.md` for the full context.
